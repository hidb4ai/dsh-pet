# Animation gallery

English · [简体中文](../../zh/reference/gallery.md) · [Documentation](../README.md)

These are bundled animation previews, not recordings of live mouse interaction. GIF filenames are stable asset identifiers. The runtime uses transparent VP9-alpha WebM assets; WebKit may need separately prepared alpha MOVs. See [custom pets](../guides/custom-pets.md) and [asset licensing](../../../dsh-pet/ASSET-LICENSE.md).
