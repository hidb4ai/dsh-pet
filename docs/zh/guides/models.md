# 选择模型服务

[English](../../en/guides/models.md) · 简体中文 · [文档首页](../README.md)

三个模型角色可以独立配置：

| 角色      | DSH 插件               | 独立模式                   |
| --------- | ---------------------- | -------------------------- |
| 聊天      | 沿用 DSH 当前模型选择  | 在开始养鱼 / AI 设置中配置 |
| 记忆整理  | 在本机长期记忆中配置   | 沿用聊天服务或单独选择     |
| Embedding | 选择文本向量服务及维度 | 选择文本向量服务及维度     |

预设包含 DeepSeek、OpenAI、通义千问（北京/新加坡）、硅基流动、火山方舟、智谱、Kimi、Ollama、LiteLLM 及自定义 OpenAI 兼容接口。预设提供连接方式，不保证你的账户拥有相应模型。没有向量预设的服务商不会出现在 Embedding 选项中。

## 配置服务

1. 选择预设并检查地址，使用自己账户和地域对应的地址及 API Key。
2. 填入 Key，点击「获取模型」，选择建议值或手动填写模型 / 部署 ID。
3. 开启记忆时，分别选择生成模型与 Embedding，向量维度必须与模型实际输出一致。
4. 先完成连接检查再启用记忆；能列出模型，不代表账户一定可以调用。

向导使用 OpenAI 兼容的 Chat Completions 和文本 Embeddings。多模态向量接口不能直接替代文本向量接口。固定维度模型可能不接受请求中的 `dimensions` 参数，预设会省略该参数，但仍核对返回的向量长度。

修改地址会清空草稿中的 Key。保存过的 Key 仅在完全相同的接口地址（包括路径）下复用，不会回显到浏览器。

## 本地模型与网关

Ollama 需要先启动服务并下载模型，再填模型名与实际向量维度。无需鉴权的本机服务可以留空 Key。

LiteLLM 是可选的独立网关，填写它的地址、密钥和模型别名。选择预设不会自动安装网关。向导未覆盖的协议可使用独立模式的模型配置，或连接已经单独配置好的 PowerContext 服务。

## 更换已有记忆库的 Embedding

已有记忆库会锁定 Embedding 地址、模型和维度，允许轮换密钥。两个模型维度相同，不代表向量空间兼容。

保留旧库，用新目录准备另一套 PowerContext 服务，重新导入保留的来源对话，验证召回后再切换桌宠的记忆服务地址。目前没有自动向量迁移；切回旧地址可以继续访问保留的旧库。
